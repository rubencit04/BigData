🚀 BigData: Ecosistema de Ingeniería y Ciencia de Datos



Este repositorio centraliza un ecosistema completo de proyectos técnicos diseñados para abordar el ciclo de vida del dato desde una perspectiva integral. La estructura está organizada en tres pilares fundamentales que permiten escalar desde la infraestructura básica hasta la implementación de Inteligencia Artificial avanzada.



🏗️ 1. DATA ENGINEERING (Infraestructura y Calidad)



En esta sección se encuentran los proyectos enfocados en el modelado, extracción y refinamiento de datos, asegurando que la información sea robusta y confiable para su consumo.



🗄️ Modelado y Bases de Datos



SQL \& Relacional: Diseño de arquitecturas de datos mediante diagramas Entidad-Relación (E-R) y optimización de consultas complejas.



MongoDB (NoSQL): Implementación de Aggregation Pipelines avanzados para el procesamiento de grandes volúmenes de datos no relacionales, incluyendo transformaciones dinámicas y enriquecimiento de colecciones.



Arquitectura con Python: Desarrollo de estructuras de datos optimizadas para la resolución de lógica de negocio y automatización de procesos de ingesta.



🧹 Calidad del Dato (Data Quality)



Análisis Exploratorio (EDA): Scripts avanzados para el descubrimiento de patrones, identificación de correlaciones y visualización estadística de variables.



Limpieza y Preprocesamiento: Detección de anomalías (Outliers), normalización de datos y estrategias de imputación para garantizar la integridad de los pipelines de datos.



☁️ 2. CLOUD ENGINEERING (Google Cloud \& IA Generativa)



Proyectos orientados al despliegue en la nube y la integración de modelos fundacionales para automatizar la seguridad y la generación de insights.



🧠 Google Cloud \& GenAI



Vertex AI / Gemini: Implementación de flujos de trabajo con modelos de lenguaje (LLMs).



Prompt Engineering: Diseño de arquitecturas de prompts (Few-shot, Chain-of-Thought) y sistemas de meta-evaluación para control de calidad.



FinOps \& Monitorización: Herramientas para el seguimiento de tokens (Input/Output) y optimización de costes operativos en la API.



🛡️ Seguridad y Automatización



Data Masking Pipeline: Sistema automatizado para la ofuscación de datos sensibles (PII) mediante técnicas de Regex y procesamiento de lenguaje, garantizando el cumplimiento normativo (RGPD) en entornos distribuidos.



🧪 3. DATA SCIENCE (Analítica Avanzada y ML)



Modelado predictivo y experimentación algorítmica para transformar los datos en conocimiento accionable.



🤖 Machine Learning Core



Modelado "From Scratch": Implementación manual de algoritmos de optimización como el Gradiente Descendente y estructuras base de Deep Learning (Perceptrón).



Aprendizaje Supervisado: Clasificadores avanzados (Random Forest, SVM, Naive Bayes) y modelos de regresión evaluados con métricas de rigor científico.



📈 Forecasting y Detección



Series Temporales: Predicción de tendencias utilizando modelos de Forecasting (Prophet y modelos estadísticos clásicos).



Detección de Anomalías: Algoritmos de identificación de patrones atípicos (Isolation Forest) aplicados a la seguridad y monitorización de sistemas.



MLOps: Trazabilidad y seguimiento de experimentos para asegurar la reproducibilidad de los modelos desarrollados.



🛠️ Stack Tecnológico



Lenguajes: Python (Pandas, Numpy, Scikit-Learn, Matplotlib), SQL, SAS.



Infraestructura: MongoDB Atlas, Google Cloud Platform, mlFlow, Git.
